# Real Pantry Gate A Alpha v0.2

Start with `static-demo/index.html` through any local HTTP server. The static build is dependency-free and exercises the six-step workflow with local persistence.

The `src/` directory contains the React/Vite version intended for the eventual multi-household build. Package installation was not available in the build environment, so the React source is supplied but not falsely represented as compiled.

Read in this order:

1. `BUILD_NOTES_v0.2.md`
2. `alpha-data/ALPHA_DATASET_README.md`
3. `GATE_A_TESTER_RULES.md`
4. `GATE_A_METRICS.md`
5. `schema-v0.2.sql`

The branded product candidates are research inputs only until audited.
