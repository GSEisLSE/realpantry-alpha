# Gate A Measurement Plan

## Core events

- `child_profile_completed`
- `seed_foods_completed`
- `week_generated`
- `item_swap_requested` / `item_swapped`
- `day_lock_toggled` / `day_locked`
- `item_lock_toggled`
- `grocery_list_opened`
- `outcome_logged`
- `week_started_again`

## Metrics to calculate

### Activation
- % of households completing onboarding.
- % generating a first five-day week.
- median quick-seed answers.
- median workable mains at generation.

### First-plan quality
- swaps per generated week.
- days locked without edits.
- % of generated components left unchanged.
- number of regeneration attempts before grocery list.

### Habit
- % generating a second week.
- % generating Week 2 without personal chasing.
- Week-4 active rate.

### Learning-loop participation
- % logging at least one lunch outcome.
- median outcomes logged per week.
- % logging three or more school days.

### Utility
- % opening grocery list.
- reported baseline weekly lunch-planning minutes.
- later: reported time spent with Real Pantry.
- perceived planning-effort reduction.

## Gate thresholds retained from the current investment memo

- ≥70% complete onboarding.
- ≥60% generate a real Week 1.
- ≥35% generate Week 2 without personal chasing.
- ≥40% log at least some returned/eaten food.
- ≥30% active in Week 4.
- ≥30% use grocery list.
- ≥50% say Real Pantry materially reduces planning effort.

Paid conversion is a later Gate C metric; Gate A should first prove repeated use.
